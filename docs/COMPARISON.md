# Qwen2.5-1.5B и Qwen3-4B на одной GPU

**600 измеряемых запросов, 0 ошибок.** Обе модели прошли генерацию, streaming, авторизацию, проверку приватности логов, кэша без сети и перезапуска.

## Условия и методика

15 ноября 2026, RTX 5070 Ti Laptop 12 ГБ VRAM, Windows / WSL 2, Docker Compose. Ноутбук подключён к сети питания при контрольных проверках. GPU-образ, код клиента и лимиты контейнера одинаковы: vLLM 0.25.1, PyTorch 2.11.0+cu130, CUDA 13.0, 6 CPU и 12 ГиБ RAM.

| Параметр | Обе модели |
| --- | --- |
| Точность | BF16 |
| Контекст / последовательности | 4096 токенов / до 4 |
| Токены в пакете / бюджет GPU | 2048 / 82% |
| Prefix caching / chunked prefill | Включены |
| CUDA graphs | Отключены, `enforce_eager=true` |
| Нагрузка | 50 запросов на случай, два размера входа, C=1,2,4 |
| Выход | 128 токенов, `temperature=0`, `ignore_eos=true` |
| Прогрев | Три полных параллельных пакета перед каждым случаем |

42 прогревочных запроса на модель исключены из задержек и пропускной способности. До прогрева выполнены проверки сервиса; загрузка весов и холодный старт в измерения не входят. Нагрузка замкнутая: одновременно выполняется не более C запросов, заданной частоты поступления нет. Модели запускались последовательно: сначала Qwen3, затем Qwen2.5.

Пользовательские тексты одинаковы. Уникальные идентификаторы стоят перед общим текстом, чтобы не получать искусственный выигрыш от одного повторяющегося префикса. Шаблон чата и токенизация различаются: Qwen2.5 получает 83 / 918 входных токенов, Qwen3 получает 63 / 898. Это сравнение одного пользовательского сценария с двумя моделями; число входных токенов не идентично.

## Память и температура

| Модель | Файлы весов, ГиБ | GPU пик, МиБ | Температура GPU, °C |
| --- | ---: | ---: | ---: |
| Qwen2.5-1.5B | 2.88 | 11105 | 40...67 |
| Qwen3-4B | 7.49 | 11083 | 41...68 |

VRAM включает рабочий стол Windows, веса, KV-кэш и служебные буферы. vLLM размещает модель и кэш в заданном бюджете, поэтому общий расход VRAM может быть близким при разном размере весов. Телеметрия снимается примерно раз в секунду и включает прогрев; короткие пики между отсчётами могут быть пропущены.

Это по одному прогону на модель на ноутбуке. Порядок запусков, фоновые процессы, температура и питание могут влиять на результат. Все измерения сохранены без удаления выбросов; они не устанавливают универсальный максимум GPU.

## Воспроизведение

Для готовых образов:

```powershell
# Qwen3
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local.ps1 -Profile qwen3-4b -SkipBuild
python scripts/check_local.py --profile qwen3-4b --output-dir results/comparison/qwen3-4b
python scripts/check_gpu.py --profile qwen3-4b --output results/comparison/qwen3-4b/environment.json
python scripts/benchmark.py --model qwen3-4b-instruct --requests 50 --concurrency-levels 1 2 4 --max-tokens 128 --warmup-rounds 3 --ignore-eos --gpu-metrics --output results/comparison/qwen3-4b/benchmark.json

# Qwen2.5 с теми же лимитами
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local.ps1 -Profile qwen2.5-1.5b -SkipBuild
python scripts/check_local.py --profile qwen2.5-1.5b --output-dir results/comparison/qwen2.5-1.5b
python scripts/check_gpu.py --profile qwen2.5-1.5b --output results/comparison/qwen2.5-1.5b/environment.json
python scripts/benchmark.py --model qwen2.5-1.5b-instruct --requests 50 --concurrency-levels 1 2 4 --max-tokens 128 --warmup-rounds 3 --ignore-eos --gpu-metrics --output results/comparison/qwen2.5-1.5b/benchmark.json
```

Без готовых образов уберите `-SkipBuild`. Для запроса используйте имя активной модели из `/v1/models`. [Хранение весов и переключение](RUNBOOK.md#выбор-модели-в-compose).
